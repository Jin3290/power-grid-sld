# Power Grid SLD Backend Service

A simplified backend service for managing Single Line Diagram (SLD) components of a power grid.

## Features

- **Component Management**: Create, read, update, delete transformers, lines, and switches
- **Measurements**: Add and track measurements for components
- **Reports**: Generate comprehensive reports asynchronously
- **Authentication**: JWT-based authentication with role-based access control
- **Validation**: Tested with 100+ components and 10,000+ measurements
